# T-Shaped-Microstrip-PCB-Antenna
Design, CST Studio Suite simulation, and experimental characterization of a T-shaped microstrip patch antenna on an FR4 substrate. Includes antenna geometry, electromagnetic simulation results, PCB prototype photographs, and measured S11 response.
