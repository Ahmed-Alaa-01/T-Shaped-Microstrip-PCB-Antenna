# T-Shaped-Microstrip-PCB-Antenna
This repository contains the design, electromagnetic simulation, and experimental characterization of a T-shaped microstrip patch antenna on an FR4 substrate. The project includes the antenna geometry, CST Studio Suite simulation files, generated electromagnetic results, PCB prototype photographs, and measured S11 response. It focuses on analyzing the antenna's electromagnetic performance and validating the simulation results through experimental measurements.
